HOW TO UPDATE package.json
==========================

Do NOT replace your whole package.json. Open it on GitHub, find the
"dependencies" block, and add these two lines inside it.

Watch the commas: every line except the last one inside the block needs a
comma at the end. A missing or extra comma is the #1 cause of build failures.

  "dependencies": {
    "@supabase/supabase-js": "^2.45.0",
    "react-icons": "^5.3.0",
    "react": "^18.2.0",
    "react-dom": "^18.2.0"
  }

(Your existing react / react-dom lines stay exactly as they are -- the two
above are the only additions.)

Commit. Vercel installs both packages automatically on the next build.
You do NOT need to run npm install yourself.

WHAT THEY ARE FOR
  @supabase/supabase-js  Real admin login + database access (Part A)
  react-icons            Social media icons in the footer (Part E)

If the build fails with "Failed to resolve import react-icons", this step
was missed or the commit did not go through.
